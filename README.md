# VIP Project

This is a full-stack web application.

## Structure

- `be/` - Backend services
- `fe/` - Frontend application

## Scripts

- `npm run dev:all` - Starts all development services concurrently.
- `npm run dev:auth` - Starts the Auth Service.
- `npm run dev:task` - Starts the Task Service.
- `npm run dev:gateway` - Starts the API Gateway.
